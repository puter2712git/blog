## 마크다운이란?

마크다운(Markdown)은 간단한 텍스트 형식으로 문서를 작성할 수 있는 경량 마크업 언어입니다. HTML로 변환하기 쉬우며, 읽기 편하고 작성이 간단합니다.

## 1. 제목 (Headings)

마크다운에서는 `#` 기호를 사용하여 제목을 작성합니다. `#`의 개수에 따라 heading의 레벨이 결정됩니다.

### 헤딩 레벨

```markdown
# H1 - 매우 큰 제목
## H2 - 큰 제목
### H3 - 중간 제목
#### H4 - 작은 제목
##### H5 - 더 작은 제목
###### H6 - 가장 작은 제목
```

- H1은 페이지당 한 번만 사용하는 것이 좋습니다 (주로 페이지 제목)
- H2-H6는 콘텐츠 구조화에 사용합니다

## 2. 텍스트 스타일

### 강조 (Emphasis)

```markdown
*이탤릭* 또는 _이탤릭_
**굵은 텍스트** 또는 __굵은 텍스트__
***굵은 이탤릭*** 또는 ___굵은 이탤릭___
~~취소선~~ (GFM)
```

결과:
- *이탤릭* 또는 _이탤릭_
- **굵은 텍스트** 또는 __굵은 텍스트__
- ***굵은 이탤릭*** 또는 ___굵은 이탤릭___
- ~~취소선~~

## 3. 리스트 (Lists)

### 순서 없는 리스트 (Unordered List)

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목
  - 또 다른 중첩된 항목
- 세 번째 항목
```

또는 `*`나 `+`를 사용할 수도 있습니다:

```markdown
* 첫 번째 항목
* 두 번째 항목

+ 첫 번째 항목
+ 두 번째 항목
```

### 순서 있는 리스트 (Ordered List)

```markdown
1. 첫 번째 항목
2. 두 번째 항목
   1. 중첩된 항목
   2. 또 다른 중첩된 항목
3. 세 번째 항목
```

### 체크박스 리스트 (GFM)

```markdown
- [x] 완료된 작업
- [ ] 미완료된 작업
- [x] 또 다른 완료된 작업
```

결과:
- [x] 완료된 작업
- [ ] 미완료된 작업
- [x] 또 다른 완료된 작업

## 4. 링크 (Links)

### 기본 링크

```markdown
[링크 텍스트](https://example.com)
[Google](https://google.com)
```

### 링크에 제목 추가

```markdown
[링크 텍스트](https://example.com "제목")
```

### 참조 스타일 링크

```markdown
[링크][ref]

[ref]: https://example.com
```

## 5. 이미지 (Images)

```markdown
![대체 텍스트](image-url.jpg)
![대체 텍스트](image-url.jpg "이미지 제목")
```

이미지를 링크로 만들 수도 있습니다:

```markdown
[![대체 텍스트](image-url.jpg)](https://example.com)
```

## 6. 코드 (Code)

### 인라인 코드

백틱(`)을 사용하여 인라인 코드를 작성합니다:

```markdown
이것은 `const variable = true;` 코드입니다.
```

### 코드 블록

3개의 백틱(``` 또는 ~~~)을 사용하여 코드 블록을 작성합니다:

```javascript
function hello() {
  console.log("Hello, World!");
}
```

```python
def hello():
    print("Hello, World!")
```

```bash
echo "Hello, World!"
npm install
```

언어 지정 시 문법 강조(syntax highlighting)가 적용됩니다.

## 7. 인용문 (Blockquotes)

```markdown
> 이것은 인용문입니다.
> 
> 인용문은 여러 줄을 포함할 수 있습니다.

> 중첩된 인용문도 가능합니다.
>> 두 번째 레벨
>>> 세 번째 레벨
```

결과:

> 이것은 인용문입니다.
>
> 인용문은 여러 줄을 포함할 수 있습니다.

## 8. 수평선 (Horizontal Rule)

```markdown
---
***
___
```

모두 동일한 수평선을 생성합니다.

---

## 9. 테이블 (Tables) - GFM

```markdown
| 헤더 1 | 헤더 2 | 헤더 3 |
|--------|--------|--------|
| 셀 1   | 셀 2   | 셀 3   |
| 셀 4   | 셀 5   | 셀 6   |
| 셀 7   | 셀 8   | 셀 9   |
```

정렬 지정:

```markdown
| 왼쪽 정렬 | 중앙 정렬 | 오른쪽 정렬 |
|:---------|:--------:|----------:|
| 왼쪽     | 중앙     | 오른쪽    |
```

결과:

| 기능 | 문법 | 설명 |
|------|------|------|
| 제목 | `# Heading` | H1 제목 |
| 굴용 | `**bold**` | 굵은 텍스트 |
| 이탤릭 | `*italic*` | 이탤릭 텍스트 |
| 링크 | `[text](url)` | 하이퍼링크 |

## 10. 특수 기능

### 취소선 (Strikethrough) - GFM

```markdown
~~이 텍스트는 취소됩니다~~
```

### 자동 링크

```markdown
<https://example.com>
<user@example.com>
```

### 이스케이프 (Escaping)

특수 마크다운 기호를 텍스트로 표시하려면 백슬래시를 사용합니다:

```markdown
\*별표\*
\[대괄호\]
\#해시\#
```

## 11. 수식 (Math Expressions)

이 블로그에서는 KaTeX를 지원합니다.

### 인라인 수식

```markdown
이것은 인라인 수식 $E = mc^2$ 입니다.
```

결과: 이것은 인라인 수식 $E = mc^2$ 입니다.

### 블록 수식

```markdown
$$
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

결과:

$$
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

## 12. 주석 (Comments) - HTML

마크다운은 HTML 주석을 지원합니다:

```markdown
<!-- 이것은 렌더링되지 않는 주석입니다 -->
```

## 베스트 프랙티스

### 1. 일관성 있게 사용하기

- 리스트에서 같은 기호를 계속 사용하세요
- 제목 또는 강조 스타일을 일관성 있게 유지하세요

### 2. 공백 활용

```markdown
# 제목

본문이 옵니다. 제목과 본문 사이에는 공백을 넣어야 합니다.

## 부제목

새로운 섹션입니다.
```

### 3. 가독성 우선

- 긴 줄은 피하고 문장 단위로 줄바꿈하세요
- 코드 블록에는 항상 언어를 지정하세요

### 4. 이미지 대체 텍스트

```markdown
<!-- 좋은 예 -->
![사용자 프로필 사진](profile.jpg)

<!-- 피해야 할 예 -->
![image](pic.jpg)
```

### 5. 링크문 명확하게

```markdown
<!-- 좋은 예 -->
[마크다운 가이드](https://example.com/markdown)

<!-- 피해야 할 예 -->
[여기](https://example.com/markdown)를 클릭하세요
```

## 마크다운 에디터

마크다운을 작성하기 위한 좋은 에디터들:

- **VS Code**: 훌륭한 기본 지원과 확장 기능
- **Typora**: WYSIWYG 마크다운 에디터 (유료)
- **Obsidian**: 강력한 로컬 노트 관리 도구
- **HackMD**: 온라인 협업 에디터
- **StackEdit**: 온라인 마크다운 에디터

## 마크다운 확장 (Flavors)

### GitHub Flavored Markdown (GFM)

GitHub에서 사용하는 마크다운의 확장판입니다:

- 체크박스 리스트
- 테이블
- 취소선
- 자동 링크

### CommonMark

마크다운의 표준 규격입니다. 일관된 동작을 보장합니다.

## 자주 묻는 질문

### Q: 마크다운에서 줄바꿈은 어떻게 하나요?

A: 문장 끝에 2개의 스페이스를 넣거나 빈 줄을 사용합니다.

```markdown
첫 번째 줄  
두 번째 줄

또는

첫 번째 줄

두 번째 줄
```

### Q: 마크다운에서 색상을 지정할 수 있나요?

A: 기본 마크다운에서는 불가능하지만, HTML을 사용할 수 있습니다:

```markdown
<span style="color: red;">빨간 텍스트</span>
```

### Q: 마크다운으로 여러 단원 문서를 만들 수 있나요?

A: 마크다운 파일을 여러 개 만들고 링크로 연결할 수 있습니다.
